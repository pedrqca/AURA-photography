## O projeto

A **Aura Fotografia** é um site desenvolvido para apresentar o trabalho de uma fotógrafa por meio de uma experiência elegante, minimalista e intuitiva.

Com uma identidade visual sofisticada, o projeto valoriza cada imagem e convida os visitantes a conhecer diferentes histórias, explorar galerias fotográficas e descobrir serviços para momentos especiais.

## Experiência

**Portfólio fotográfico**

Galerias organizadas por categorias para explorar registros de casamentos, aniversários, chás de bebê, ensaios fotográficos e momentos em família.

**Uma identidade sofisticada**

Uma combinação de tons escuros, detalhes dourados e tipografia elegante que mantém o foco no que realmente importa: as fotografias.

**Conexão com o cliente**

Uma experiência que facilita o acesso aos serviços e aos canais de contato, aproximando a fotógrafa de pessoas que desejam eternizar momentos especiais.
